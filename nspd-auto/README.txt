БЫСТРЫЙ СТАРТ
──────────────
1. Откройте coords.csv и введите свои координаты (широта, долгота)
2. Запустите УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat
3. Следуйте инструкциям на экране


СТРУКТУРА ПАПКИ
────────────────
  coords.csv                  ← Ваши координаты (редактировать!)
  coords_example_geojson.json ← Пример в формате GeoJSON
  main.py                     ← Основной скрипт
  УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat  ← Запустить двойным кликом
  requirements.txt            ← Зависимости Python


КАК РАБОТАЕТ СКРИПТ
─────────────────────
1. Открывает сайт НСПД в браузере Chromium
2. Ждёт пока ВЫ откроете нужный раздел и активируете инструмент
   рисования полигона (карандаш / "Нарисовать зону")
3. Вы нажимаете ENTER в консоли
4. Скрипт определяет текущий вид карты и вычисляет,
   куда кликнуть для каждой координаты
5. Автоматически кликает на все точки по порядку
6. Замыкает полигон кликом на первую точку
7. Вы сохраняете зону в интерфейсе НСПД


ФОРМАТ coords.csv
──────────────────
Вариант 1 — с заголовком:
    lat,lon
    55.751244,37.618423
    55.752100,37.620000
    ...

Вариант 2 — без заголовка (просто два столбца):
    55.751244,37.618423
    55.752100,37.620000
    ...

Разделитель: запятая или точка с запятой
Десятичный знак: точка или запятая (оба варианта работают)
Порядок: точки должны идти ПО ПОРЯДКУ обхода контура зоны


ФОРМАТЫ ФАЙЛОВ КООРДИНАТ
──────────────────────────
  coords.csv                 — CSV (lat/lon)
  coords.json                — JSON массив [[lat,lon], ...]
  coords.geojson             — GeoJSON (Polygon / FeatureCollection)

Пример запуска с другим файлом:
    python main.py мой_файл.geojson
    python main.py координаты.csv --slow


ВАЖНО: МАСШТАБ КАРТЫ
──────────────────────
Перед тем как нажать ENTER, убедитесь что:
  ✓ На карте видны ВСЕ точки вашей зоны
  ✓ Карта достаточно приближена (иначе клики будут неточными)
  ✓ Активирован инструмент "рисования полигона" на НСПД

Чем сильнее приближена карта → тем точнее расстановка точек.


ОШИБКИ И РЕШЕНИЯ
──────────────────
"Python не найден"
  → Установите Python 3.9+ с https://python.org
    При установке отметьте "Add Python to PATH"

"playwright не установлен"
  → Запустите bat-файл повторно, он установит автоматически
  → Или вручную: pip install playwright && playwright install chromium

"Не удалось определить тип карты"
  → Введите границы вручную (скрипт спросит)
  → Или используйте --slow для медленного режима

"Точки ставятся не туда"
  → Приблизьте карту сильнее перед запуском
  → Убедитесь что все точки видны на экране
  → Запустите с --slow и проверьте первую точку
